Project inspired by UCB's CS61B Gitlet. The reason I started this project is because Git and GitHub genuinely confuse me so I figured building a mini version of Git would help me understand what is going on under the hood.

This project is meant to be a slightly more complex version of the CS61B project (and is written in Python instead of Java). The project does not use an online tutorial or online notes. It was architected with my brother over my winter break—we sat down with my iPad and went through what I wanted my MiniGit to do. It's evolved a lot since we scratched out that plan but the main ideas come from that.

This `README.md` file hopefully will be updated periodically as I progress throughout the project.  

So far, I have implemented various functions, as seen in file `minigit.py` with the terrible ugly if statements (I promise I'll fix that at some point). I have not yet run many real tests and have definitely not gone looking for edge cases. Some things I'd like to implement is a global commit log, change the entry point to using a dispatch table, make the try/except logic when checking if a commit exists a bit more Pythonic, and add a config file. Once I finish up all that I'll probably take a real look at the CS61B website and see if they've got some cool functions that I missed.
